# ADR-070: Host observations and scoped agent reports

Status: Accepted
Date: 2026-10-25

The owner approved explicit host inference/validation facts alongside agent
repository/tool-action narration. Repeated bounded reviews exposed ambiguity
between agent tool actions and host inference/bookkeeping effects. Strict host-wide
interpretation was the alternative; it requires correction of every unqualified
negative effect statement even when repository actions and technical findings are sound.

The CLI presents recorded adapter attempts and completed responses separately from
the retained agent report. Missing observations remain unknown. Counts describe
instrumented adapter calls in the invocation, never a census of network traffic or
opaque external-client inference. Existing deterministic validation remains host
evidence; the scope label does not verify arbitrary technical claims or establish
absence of all filesystem effects.

The contract is supplied before inference and to final scrutiny. Raw reports remain
unchanged in conversation storage. New scoped reports carry scope and observation
metadata into history; unmarked older reports retain their original interpretation.
Required/advisory scrutiny policy, privacy and inference grants remain unchanged.

This choice makes authorship and observation limits visible without rewriting model
reports. Its cost is additional closeout/history context and the continuing need
for evidence and substantive review of technical claims. It applies prospectively;
consumed acceptance trials retain their original results.
