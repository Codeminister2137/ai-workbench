# Inbox task template

Copy the body below when filing generic `task` items. Keep every section
and the blank lines between them.

```text
Goal: [FILL: one sentence — the concrete outcome]

Context:
[FILL: refs and prior work — inbox:ids, commits, docs, runs]

Scope:
[FILL: what is included; explicit non-goals]

Done when:
[FILL: verifiable completion conditions]
```
