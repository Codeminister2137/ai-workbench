# ai-workbench (root project)

Provider-agnostic AI infrastructure, orchestration, and the applications
built on them — one modular monolith, portfolio-quality, understandable
by one developer.

Key areas: `packages/ai_provider` (provider adapters), `packages/ai_orchestrator`
(routing, planning, spend), `packages/ai_agent` (execution substrate),
`apps/` (products), `company-site/`.

Current state: see the workbench Roadmap (Plans tab) and
`docs/plans/repo-gap-assessment-20261117.md`.
